# Framer-eksport – marinorntnu.no

Råmateriale fra Marinor NTNU sin Framer-side, hentet 25.09.2026. Selve analysen står i
[`docs/framer-analyse.md`](../docs/framer-analyse.md).

| Mappe | Innhold |
|---|---|
| `source/` | Original TSX-kildekode for alle 44 kodefiler i Framer-prosjektet (hentet fra Framers source maps), pluss override-filen `Team2025Effects.tsx`. `SiteKit.tsx` er designsystemet. |
| `images/` | Alle 37 bilder i original oppløsning, med beskrivende filnavn (`logo/`, `argus/`, `team/`, `competitions/`, `sponsors/`). `manifest.json` viser Framer-URL og mål for hvert bilde. |
| `screenshots/` | Helsides skjermbilder av alle 13 sider: `<side>__desktop.jpg` (1440 px), `__tablet.jpg` (810 px) og `__phone.jpg` (390 px). |
| `live/` | Det som faktisk vises på hver side: `<side>.txt` (all synlig tekst) og `<side>.json` (tekst, bilder med alt-tekst og størrelse, lenker, overskrifter, meta-tagger). |
| `site/` | `sitemap.xml`, `robots.txt`, `head-tags.html` (meta/favicon fra forsiden) og `searchIndex.json` (Framers søkeindeks med all tekst per side). |

Merk: bildene tilhører Marinor NTNU. Sponsorlogoene tilhører de respektive selskapene.
