Seven groups

Our groups.

These are our seven groups. Have a look, so you know which one to apply for.

  1. 01

    Perception

    LiDAR, cameras and the software that lets the boat understand what is around it.

    • Sensors
    • Computer vision
    • Data
  2. 02

    Autonomy

    Planning and decision making, so the boat finds a safe route on its own.

    • Path planning
    • Algorithms
    • Simulation
  3. 03

    Control

    Steering and thrust. Keeps the boat on the planned path in wind and waves.

    • Control theory
    • Modelling
    • Testing
  4. 04

    GUI

    The interface where we follow the boat, read its data and send it commands.

    • Web
    • UX
    • Visualisation
  5. 05

    Hardware

    Hulls, frame, power and electronics.

    • Electronics
    • CAD
    • Building
  6. 06

    Economy

    Budget, sponsors, travel and other practical work.

    • Budget
    • Sponsors
    • Applications
  7. 07

    PR

    Social media, photos and this website.

    • Content
    • Design
    • Web
